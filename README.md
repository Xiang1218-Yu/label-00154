# 烟叶风味多标签分类模型

基于随机森林算法的烟叶风味多标签分类系统，通过品质指标预测烟叶的ABC三类风味标签。

## How to Run

### Docker启动（推荐）

1. 准备数据文件
```bash
# 将数据文件 peifutf8.csv 放置到 backend/data/ 目录下
mkdir -p backend/data
cp /path/to/peifutf8.csv backend/data/
```

2. 构建并运行
```bash
docker compose up --build -d
```

3. 查看运行日志
```bash
docker compose logs -f
```

4. 查看输出结果
```bash
# 分析报告和图表保存在 backend/output/ 目录
# 训练好的模型保存在 backend/models/ 目录
ls backend/output/
ls backend/models/
```

5. 停止服务
```bash
docker compose down
```

### 本地启动

1. 创建虚拟环境
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 准备数据
```bash
# 将数据文件 peifutf8.csv 放置到 backend/data/ 目录下
mkdir -p data
cp /path/to/peifutf8.csv data/
```

4. 运行程序
```bash
python main.py
```

## 题目内容

我邀请5名专业感官测评人员组成的评审组，评价了150个烟叶样品的风味特征，我让他们给这些烟叶贴上ABC三类风味标签，对于某一个烟叶大部分专家直贴了其中一个标签，但是有部分专家给烟叶贴了不止1个标签，这样就产生了这样的评价数据：对于每一个烟叶都会有ABC三类风味的得分率，比如对于某一个烟叶的评价中，有5位专家贴了A标签，其中还有3位专家贴了AB标签，2位专家贴了AC标签，那么这个烟叶风味评价结果数据中就有三个数据：标签A得分率为100%，标签B得分率为30%，标签C得分率为20%。当某个标签得分率超过一定阈值时，我们认为该样品具备该风味，在本次实验中，我们将该阈值定位50%；同时我使用仪器和化学分析方法分析了这些烟叶样品的几十个个品质指标(品质指标包括化学、物理、外观、评吸四类)，请根据专业人员贴的风味标签和我测的各种品质指标，帮我建立通过随机森林算法建模方法找出根据品质指标判断烟叶风味的多标签分类模型。 
我已经将数据整理到一个有标题行csv文件中（文件名peifutf8.csv），字段包括：样品编号,省份,品种,等级,部位,香型,样品类别,A得分率,B得分率,C得分率,香型风格,彰显程度,香气质,香气量,透发性,杂气,刺激性,余味,甜感,浓度,细腻程度,劲头,可用性赋分,烟气特征,香气特征,口感特征,总植物碱,总氮,还原糖,总糖,钾,氯,淀粉,厚度,密度,单叶重,平衡含水率,拉力,伸长量,填充值,含梗率,叶片结构,成熟度,油分,色度,身份,颜色；其中样品编号,省份,品种,等级,部位,香型,样品类别 等字段为字符型，样品编号 为每个样品的唯一编号，没有重复；省份,品种,等级,部位,香型,样品类别 为分类字段，有重复。其余字段为品质指标，为浮点型，这些个品质指标又可以分为四类，评吸指标：香型风格,彰显程度,香气质,香气量,透发性,杂气,刺激性,余味,甜感,浓度,细腻程度,劲头,可用性赋分,烟气特征,香气特征,口感特征；化学成分：总植物碱%,总氮%,还原糖%,总糖%,钾%,氯%,淀粉%；物理特性：厚度,密度,单叶重,平衡含水率,拉力,伸长量,填充值,含梗率；外观质量：叶片结构,成熟度,油分,色度,身份,颜色。 
在建模时候，数据集要随机划分为：训练集、验证集和测试集，比例为7:2:1。数据分析过程要按照五个分析步骤（数据预处理、特征工程、模型构建、验证体系和实施优化）进行，首先进行数据预处理，包括数据缺失值处理和数据标准化，在报告中给出数据化过程和标准化后数据基本情况，然后进行递归特征消除算法进行初步筛选，得到多个关联特征，请在报告中列出具体的初步筛选后特征，再基于互信息值分析进行关联特征的二次筛选，通过计算关联特征与配方作用标签的互信息值，基于阈值得到关键品质指标；在报告中列出阈值和筛选前后指标变化情况，利用筛选到的关键品质指标，生成了更多的特征交互项，关键品质指标和特征交互项共同组成了关键品质指标子集，然后以关键品质指标子集作为数据集，按7:2:1的比例将其随机划分为训练集、验证集、测试集，为模型训练、超参数优化及性能验证提供数据基础；在报告中列出随机森林模型参数和超参数优化后的最优参数，通过混淆矩阵算法对验证集预测结果进行量化评估，以确认最优超参数配置对模型泛化能力的正向作用；将测试集输入所述多标签分类模型对烟叶配方作用进行预测，基于准确率、精确率、召回率及F1分数指标，验证模型的精准预测能力；获取待评估烟叶的关键品质指标和特征交互项，输入所述多标签分类模型，得到配方作用预测结果；模型同时输出关键品质指标的特征重要性排序，以明确各关键品质指标对烟叶配方作用的重要性和贡献度。上述信息均需要在报告中体现。请给出完整可执行的代码，在执行过程生成执行过程文档，在报告给出详细过程解释和结果展示，文档中要有丰富的图表数据，对于每一个步骤的详细说明、模型性能的评估参数相关图表、结果解读均在过程文档中体现。我在使用Windows10系统的运行Python，请注意输出图表中中文显示的问题。

### 数据说明

- **样本数量**: 150个烟叶样品
- **标签阈值**: 50%（当某个标签得分率超过50%时，认为该样品具备该风味）
- **数据集划分**: 训练集:验证集:测试集 = 7:2:1

### 品质指标分类

1. **评吸指标**: 香型风格、彰显程度、香气质、香气量、透发性、杂气、刺激性、余味、甜感、浓度、细腻程度、劲头、可用性赋分、烟气特征、香气特征、口感特征

2. **化学成分**: 总植物碱、总氮、还原糖、总糖、钾、氯、淀粉

3. **物理特性**: 厚度、密度、单叶重、平衡含水率、拉力、伸长量、填充值、含梗率

4. **外观质量**: 叶片结构、成熟度、油分、色度、身份、颜色

### 分析流程

1. **数据预处理**
   - 缺失值处理（均值/众数填充）
   - 数据标准化（Z-score标准化）

2. **特征工程**
   - 递归特征消除(RFE)初步筛选
   - 互信息值分析二次筛选
   - 特征交互项生成

3. **模型构建**
   - 随机森林多标签分类模型
   - 网格搜索超参数优化

4. **验证体系**
   - 混淆矩阵评估
   - 准确率、精确率、召回率、F1分数

5. **实施优化**
   - 模型保存与加载
   - 特征重要性排序

### 输出内容

- `output/analysis_report.md` - 详细分析报告
- `output/*.png` - 可视化图表
- `models/tobacco_flavor_model.pkl` - 训练好的模型
- `models/feature_engineering_params.pkl` - 特征工程参数
